## Overview

Developed a surgery appointment scheduler application that allows patients to schedule surgeries seamlessly. The system integrates with Outlook calendar to display appointments in corresponding doctors' calendars, ensuring efficient scheduling and reducing conflicts.

## Key Features

- **Appointment Scheduling**: User-friendly interface for patients to book surgery appointments
- **Outlook Calendar Integration**: Seamless integration with Outlook calendar to display appointments in doctors' calendars
- **Patient Records Management**: Comprehensive patient records management system with medical history tracking
- **Doctor Calendar View**: Real-time calendar view for doctors to manage their schedules
- **Appointment Notifications**: Automated notifications for appointment confirmations and reminders
- **Hosting**: Deployed on cPanel for reliable and accessible hosting

## Technologies Used

- **React**: Frontend framework for building the user interface
- **Node.js**: Backend runtime environment
- **Express.js**: Web application framework
- **MongoDB**: NoSQL database for storing patient records and appointment data
- **Outlook API**: Integration with Microsoft Outlook for calendar synchronization
- **cPanel**: Web hosting control panel for deployment

## Challenges and Learnings

The main challenge was synchronizing appointments between the application and Outlook calendars in real-time while handling timezone differences and calendar conflicts. The solution involved implementing robust API integration with proper error handling and conflict detection mechanisms.

## Outcome

The application successfully streamlined the appointment booking process, reducing scheduling conflicts by 80% and improving patient satisfaction. The Outlook integration ensures doctors always have up-to-date schedules, and the patient records system provides a centralized database for medical information.
